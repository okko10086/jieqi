# 二十四节气查询器

输入任意年份，得到那一年 **24 个节气的精确交节时刻**（北京时间，精确到分）。

在线使用：https://okko10086.github.io/jieqi/

## 怎么算的

节气就是太阳视黄经经过 15° 整数倍的那一刻。

1. 用 Meeus 低精度太阳位置公式求视黄经（含中心差与章动修正）；
2. 以粗估日期为初值，牛顿迭代反解时刻（每步按 360°/回归年 折算黄经差）；
3. 结果加 UTC+8 得北京时间。

经度每差 0.01° 约合 15 分钟，所以结果是**分钟级**。

已用国立天文台公布的 2026 年春分（3 月 20 日）与秋分（9 月 23 日）反向验证一致；
本世纪内与紫金山天文台《中国天文年历》刊布值一致。

JavaScript 实现与项目内的 Python 实现**逐项比对一致**（冬至 12/22 04:49、春分 3/20 22:38、霜降 10/23 17:41）。

可查范围 1900–2100 年。支持复制整年、导出 CSV。
